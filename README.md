# TabVerse

[English](./README.en.md)

Chrome 新标签页信息聚合仪表盘

一个让 Chrome 新标签页更好用、信息更聚合的浏览器扩展。

默认的新标签页只有一个搜索框和背景图，TabVerse 把它变成一个简约风格的信息聚合仪表盘（卡片式布局，设计语言参考 [XTab](https://github.com/pkc918/XTab)）：

![GitHub Profile 页面](screenshots/github.png)

| 功能 | 说明 |
|------|------|
| 🔍 聚合搜索 | Google / Bing / 百度 / DuckDuckGo / GitHub 引擎下拉切换（可在设置中设定默认）；输入网址直接打开；输入时展示搜索联想建议（键盘上下键选择）；按 `/` 快速聚焦 |
| 🔗 快捷访问 | 胶囊式常用网站，「管理」模式下可添加 / 编辑 / 删除、拖拽排序，自动抓取站点图标，失败时回退字母头像 |
| 🔖 浏览器书签 | 按文件夹逐层浏览（面包屑导航），双栏视图支持「默认排序 / 最近添加」；全局关键字搜索同时命中书签与文件夹——命中的文件夹作为独立结果行展示（含书签数量，点击直接进入该文件夹） |
| ✅ 待办事项 | 添加 / 完成 / 删除 / 一键清除已完成，支持截止日期与优先级（逾期自动提示），本地保存 |
| 🌤️ 天气 | 免费开源 Open-Meteo 数据，自动 IP 定位 |
| 📰 RSS 订阅 | 添加 / 删除 / 排序订阅源，点击标题自动标记已读，支持「全部已读」，已读状态本地保存 |
| 🐙 GitHub 面板 | Discover 热门 / 新晋仓库与 Profile 贡献热力图；可选 OAuth 登录，将 API 配额由 60 次/时提升至 5000 次/时 |
| 🗂️ 标签页框架 | 内容区按标签页组织模块，副栏一键切换「快捷访问 ⇄ 标签页」 |
| 🕐 时钟问候 | 实时时钟、日期与分时段问候（可在设置中选择时区） |
| ☀️ 深浅色 | 点击右上角图标切换深浅模式 |
| 🌐 多语言 | 简体中文 / English，可跟随浏览器语言自动切换（设置 → 语言） |
| 🧘 简约模式 | 一键隐藏所有面板，只保留时间日期与搜索框，适合做纯粹的极简新标签页 |
| 🖼️ 自定义背景 | 简约模式下使用图片 / 视频背景（本地文件或网络 URL），可调节遮罩透明度保证文字可读 |

数据仅保存在浏览器扩展存储中（`chrome.storage.sync` / `chrome.storage.local`），无任何自建服务器或第三方上报；登录 Chrome 并开启同步时，`sync` 中的数据会通过 Chrome 自带的扩展同步机制随 Google 账号在设备间漫游，未登录或关闭同步时仅存本机。

## 技术栈

**WXT + Vue 3 + TypeScript**

- [WXT](https://wxt.dev/)
- Vue 3 + Composition API
- TypeScript（零类型错误）

## 安装

1. 执行 `pnpm build`
2. 打开 Chrome，进入 `chrome://extensions`
3. 开启开发者模式 → 加载已解压的扩展程序 → 选择 `.output/chrome-mv3/`
4. 打开新标签页即可体验

## 更新记录

- **v0.6.1**（当前）：修复快捷访问 / 待办 / RSS 订阅源编辑后刷新不保存的问题——Vue 响应式（Proxy）数组直接传给 `chrome.storage` 时会被序列化成普通对象而非数组，刷新后形状校验失败即回退默认数据，表现为编辑「恢复原样」；写入侧先把数据归一化成纯数据再存储，读取侧兼容旧的对象形状数据并自动恢复
- **v0.6.0**：书签搜索支持文件夹命中——命中关键词的文件夹不再展开整棵子树，改为独立结果行（显示书签数量与进入按钮，点击进入该文件夹并清空搜索词），子级中单独命中的书签 / 子文件夹仍逐条展示且文件夹排在前，空文件夹或只含子文件夹命中时不再误报「未找到」；优化普通 / 简约模式切换过渡动画（淡入淡出 + 轻微缩放位移，切回普通模式不再卡顿，修复新开标签页先闪现普通模式），自定义背景层改为淡入淡出并在隐藏后自动暂停视频
- **v0.5.0**：新增简约模式（仅显示时间日期与搜索框，右上角一键进入 / 退出）与自定义背景（仅简约模式下显示，图片 / 视频，支持本地文件与网络 URL、遮罩透明度调节，视频页面隐藏时自动暂停）；界面多语言（简体中文 / English，设置中可选，默认跟随浏览器语言），时钟日期、天气、GitHub 动态等文案随语言切换；设置面板新增主题分段切换、语言、时区与默认搜索引擎选择，数据管理按钮重设计为带图标的边框按钮（适配主题）；搜索框在简约模式下使用毛玻璃半透明样式
- **v0.4.0**：订阅源支持删除（chip 悬停 ✕），Google Research 改用官方 RSS 源并自动迁移老配置；GitHub 数据 30 分钟本地缓存 + 限流状态持久化——限流窗口内打开新标签页直接显示倒计时、不再发无效请求，重置后自动重试；书签双栏视图（左目录树 + 右书签，右上角图标切换，搜索跨视图可用），右栏支持「默认排序 / 最近添加」；站点图标两级本地缓存（内存 + `chrome.storage.local`，并发去重、容量上限）；搜索框输入时展示 DuckDuckGo 联想建议（键盘上下键选择、前缀缓存）；快捷访问支持拖拽排序与点击编辑；待办支持截止日期与优先级（逾期未完成自动提示）；RSS 点击标题即记已读、支持「全部已读」，已读状态本地持久化；GitHub 面板可选 OAuth 登录（Device Flow，令牌仅存本地，API 配额由 60 次/时提升至 5000 次/时）；设置支持导出 / 导入；修复相对时间显示负号、副栏按钮与内容列宽度错位等问题
- **v0.3.0**：初始版本。WXT + Vue 3 + TypeScript 全新实现：聚合搜索、快捷访问、天气、待办、书签面包屑目录浏览、标签页框架（快捷访问 ⇄ 标签页）、RSS 阅读与 GitHub Discover / Profile 面板、深浅色

## 隐私

- 不收集任何数据
- 天气、图标、搜索建议走公开免费接口
- 仅申请 `storage`、`bookmarks`、`unlimitedStorage` 三个 API 权限；另声明通配符主机权限（`*://*/*`）用于绕过 CORS 直连读取 RSS 订阅源与获取站点图标，仅向对应站点发请求
